The arithmetic source register pins URLs, revisions, licenses, and reuse modes.
The Natural Number Game supplies licensed early-arithmetic coverage; *The
Mechanics of Proof* is used only as a reference-only curriculum; *An
Illustrated Theory of Numbers* and its GPL notebooks are external algorithm
indexes.

Peano statements and proof scripts are reconstructed independently and accepted
only through the [[trusted-kernel]]. No unlicensed prose or code and no GPL
notebook implementation is copied into the MIT/CC BY-SA repository.

The generated artifact binds each checked statement, script, dependency list,
certificate hash, and certificate metrics. Hashes expose drift but are not
proof authority.

The current 183-theorem artifact has ordered root
`09359430226349a7d5fdd1fd67376d345bc1bb5f707e746e8b58c2799086f2d6`.
Its binary-CRT, bounded-prefix β-coprimality, product-coprimality, and fold-step
tranches are independently authored in the native tactic language; external
CRT and Gödel-β sources provide mathematical orientation, not imported proof
code.
