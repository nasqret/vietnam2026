# Obsidian vault

Open this folder as a vault in [Obsidian](https://obsidian.md). Start at [`moc/00-index.md`](moc/00-index.md). Notes are atomic and wiki-linked; the graph view shows the concept structure behind the [knowledge book](../book).

The foundational arithmetic library starts at
[`moc/arithmetic-library-moc.md`](moc/arithmetic-library-moc.md). Its 189 files
under `lemmas/` are generated from the checked runtime DAG by
`scripts/build_arithmetic_vault.py`; edit the theorem source or the generator,
then rebuild rather than hand-editing those notes.
The verified graph currently has 268 notes and 2,513 resolved wikilinks.
