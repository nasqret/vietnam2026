## Mathematical boundaries

Arithmetic functions are actual finite beta-coded tables of canonical signed
integers, not higher-order function variables or an infinite table code.
Convolution uses genuine positive divisors and their actual quotient
witnesses. Associativity uses a proved finite Fubini interchange. Möbius
inversion uses the constructed Möbius table and proved divisor cancellation.

General inverses satisfy the exact criterion

```text
Table(N,F) -> ((exists G. Inverse(N,F,G)) <-> (N=0 or UnitAtOne(F))).
```

`UnitAtOne(F)` means the actual value at one is signed +1 or -1. Its
definition is not a restatement of invertibility. The inverse definition
requires both actual convolution unit equations, not the criterion as an
extra premise. The construction solves each strict-prefix triangular
equation and extends the real beta table. Values at zero remain arbitrary;
uniqueness concerns positive indices in the represented prefix.

This closes the finite Möbius-inversion contract G007. It does **not** close
G009's remaining multiplicative-convolution obligation or G091. Normalized
multiplicativity requires +1, not either signed unit. The nonempty positive
prefix, coprime-product and in-prefix bound hypotheses must be stated and
proved explicitly in the subsequent G009 layer.

The earlier Euler-unit research family is admitted at the same time. Its
`euler_coprime_totient_power` endpoint supplies an actual power witness for
every nonzero modulus, including modulus one; `euler_theorem_for_units`
records the explicit-unit formulation. These exact admitted statements close
G014 in the combined atlas. Both G007 and G014 are recorded as completed
named targets of this promotion; G009 and G091 remain explicitly open.

## Literal historical evidence

The 740 inherited document records retain their original paths, roles, byte
counts and hashes. Five historical versions no longer occupy the shared
working-tree paths: three differ by a final newline, one Bertrand RFC by four
Markdown line-break spaces, and the WMI replay log has a legitimate later

provenance. Neither the historical records nor the current files are rewritten.
Only those five reviewed versions can resolve to archives; every other
inherited record must match its actual current file. Missing or modified
archives fail closed. The resolver and all archive bytes are bound to the
fresh proof invocation and the live publication context. Metadata preflight
runs before the expensive proof jobs and grants no proof authority.

## Bounded catalogue transport

The immutable v30 catalogue is 66,503,303 bytes, close to the existing 64 MiB
document limit. V31 uses a small manifest referencing exactly two data
documents: that literal unchanged parent and a same-directory delta of 574
complete new records. This is not a proof-reference format and never grants
checked-use authority by itself. Logical loading preserves every parent
record and concatenates the exact ordered delta.

Each input retains the original 64 MiB limit. Only the two literal local
filenames are accepted; no recursive manifests, URLs, symlinks, path
traversal, duplicate JSON keys, non-finite numbers or ambiguous integer
fields are accepted. Counts, ownership, complete ordered dependencies,
historical evidence and first-admission provenance are checked. A service
cache authenticates and fingerprints all three files, not only the small
manifest. The mathematical kernel and proof resource limits are unchanged.

## Proof and publication gates

Every fresh family job checks the complete actual bundle with the original
intuitionistic HA kernel, then passes the very same bytes to the existing
independently compiled Lean verifier. Every exact principal has a separate
ordinary empty-context certificate check. Each job retains 170/175 CPU
seconds, 180 wall seconds and 1,536 MiB peak RSS. Scheduling independent jobs
does not enlarge a proof window. Saved receipts are evidence outputs, never
inputs authorizing a skipped check.

The exporter also verifies exact FormulaDAG novelty, the unmodified parent
and Stable artifacts, the full theorem dependency DAG, source provenance,
the complete evidence partition and the immutable channel default. A live,
source-bound result may be passed directly to the publication adapter within
the same invocation; a JSON file or success flag cannot mint that result.

Publication creates separate canonical Quadratic Reciprocity-style readers
and a combined campaign successor. Historical local/published research
snapshots stay byte-identical and retain their non-admission statements as
historical facts. New readers distinguish first admission v31 from those
earlier proof checkpoints. Definition dependencies, theorem dependencies
and conceptual campaign links remain separate edge kinds. No broad goal is
completed merely because one supporting lemma was admitted.

Faculty proof-site deployment and Peano application production are separate
workflows. Production still requires the clean-commit staging, exact-byte,
cache-header and compression gates. This admission does not change training
authority, run a training experiment, merge the milestone branch into main,
or bypass any hosting or permission requirement.
