# Constructive negative-oriented quaternion modular blocks

This isolated tranche supplies the two negative-heavy canonical sign patterns
needed by centered four-square descent:

1. Four negative centered-coordinate orientations produce four balanced
   congruences for the conjugate quaternion identity.
2. One positive first orientation and three negative remaining orientations
   produce the four balanced congruences for the ordinary Hamilton identity.

Each theorem assumes only that the centered four-square norm is zero modulo
the multiplier and the four stated orientation congruences. Scalar blocks use
constructive zero-balance aggregation and cancellation; vector blocks use the
already independently checked positive/negative crossed-product lemmas.
