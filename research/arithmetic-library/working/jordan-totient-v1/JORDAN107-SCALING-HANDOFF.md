## Exact next cardinality target

The next mathematical work must lift the actual coordinate bijection to
actual finite enumerations, not merely assert its host-model cardinality.
For a prime p and width k>0, with real power witnesses

```
Pow(p,h,A), Pow(p,S h,N), Pow(A,k,U), Pow(N,k,W), Jordan(k,N,j),
```

prove the natural-arithmetic identity

```
j + U = W.
```

Required remaining bridges are: a complete duplicate-free enumeration of the
canonical N-box of cardinality W; transport of the A-box enumeration through
the checked scaling bijection to the all-p-divisible subbox of cardinality U;
an actual decidable partition into divisible and nondivisible tuple lists;
coverage, disjointness, index injectivity and the resulting sum of counts.
The checked positive-prime-power primitive characterization then identifies
the nondivisible list with the actual Jordan enumeration, using count
uniqueness. The existing power successor law aligns N with p*A.

Only after that counting theorem should one package the subtraction-free
product form: if `Pow(p,k,V)`, `S t=V`, `Pow(A,k,U)` and the above positive
prime-power hypotheses hold, prove `Jordan(k,N,U*t)` (and the equality with
any independently witnessed Jordan count). Multiplicativity over a finite
list of distinct-prime powers must then use actual pairwise coprime factors
and the checked `Jordan(k,1,1)` base. Neither final formula is claimed here.
