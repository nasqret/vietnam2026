# Peano Hydra artifacts

This directory contains reproducible evidence from the pre-H0 Hydra plumbing
bootstrap. It contains no trained-model result and no sealed benchmark.

`teacher-oracle-pilot-v1.json` is generated by:

```console
python3 scripts/eval_peano_hydra.py \
  --include-trace \
  --output /tmp/teacher-oracle-pilot-v1.json
cmp /tmp/teacher-oracle-pilot-v1.json \
  artifacts/peano-hydra/teacher-oracle-pilot-v1.json
```

The CLI creates output exclusively and refuses to overwrite prior evidence.
Generate to a fresh path, compare it byte-for-byte with the committed artifact,
and only replace the artifact deliberately when its experiment version changes.
The reviewed v1 file has SHA-256
`3b709f70eb910e327880fefb0fb54b0770e5a8662c995205412f261b27b7580d`.

The experiment replays the existing 13-command, 180-node consecutive-product
proof. Both lanes receive the same fixed symbolic candidates and search
budgets. The hybrid lane additionally receives structural actions copied from
the checked script at their exact canonical states; the control receives an
identified null head with the same quota. A related mutated theorem is also
attempted to verify that the state-keyed transcript is not reused.

The result establishes only that the untrusted portfolio, exact-state gate,
surface tactics, retained traces, and fresh original-goal kernel replay compose
correctly. Because the structural route is a teacher oracle and the contextual
symbolic candidate was human-selected for this example, it is not evidence of
Qwen or Codex capability, an LLM advantage, a general symbolic baseline, or a
negative decision for the mutated formula.

Every lane is explicitly marked comparison-ineligible: surface-macro-v0 does
not yet retain raw decoder calls or resource records, validate a campaign
provider attestation, or discover critical frontiers independently.
