MC0013

beta_signed_dot_product_exists_unique

Every arbitrarily long beta-coded signed vector pair has exactly one positive/negative dot-product pair.

Alpha v30 checked-use · first admitted v21 · independently kernel and Lean verified; not Stable

Historical partial components only: this chapter proves arbitrary natural and signed matrix multiplication and signed two-/three-dimensional determinants. T13 is now closed in the separate Alpha-v27 integer-linear-algebra branch with arbitrary determinant data, rank, and integer column spans; lattice index and normal forms are outside that scope.
