odd_mod4_cases

Every odd natural is congruent to one or three modulo four.

candidate display only This reading surface grants no kernel, review, freeze, training, retrieval, or evaluation authority.

Exact selected statement

forall n. (exists h. n = 2 * h + 1) -> (exists a. n = 4 * a + 1) \/ exists b. n = 4 * b + 3

Canonical: ∀ x. (∃ y. x = 2 · y + 1) → (∃ y. x = 4 · y + 1) ∨ (∃ y. x = 4 · y + 3)
