odd_half_exists_unique

Every odd natural has a unique half witness.

candidate display only This reading surface grants no kernel, review, freeze, training, retrieval, or evaluation authority.

Exact selected statement

forall n. (exists a. n = 2 * a + 1) -> exists h. n = 2 * h + 1 /\ forall k. n = 2 * k + 1 -> h = k

Canonical: ∀ x. (∃ y. x = 2 · y + 1) → ∃ y. x = 2 · y + 1 ∧ (∀ z. x = 2 · z + 1 → y = z)
