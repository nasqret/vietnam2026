mod5_fourth_power_one

A fourth power of a nonmultiple of five is one modulo five.

candidate display only This reading surface grants no kernel, review, freeze, training, retrieval, or evaluation authority.

Exact selected statement

forall n. ~(exists x. n = 5 * x) -> exists x. n * n * n * n = 5 * x + 1

Canonical: ∀ x. ¬(∃ y. x = 5 · y) → ∃ y. x · x · x · x = 5 · y + 1
