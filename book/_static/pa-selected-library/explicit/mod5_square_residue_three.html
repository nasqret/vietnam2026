mod5_square_residue_three

Squaring residue three modulo five gives residue four.

candidate display only This reading surface grants no kernel, review, freeze, training, retrieval, or evaluation authority.

Exact selected statement

forall z q. z = 5 * q + 3 -> z * z = 5 * ((q * z + 3 * q) + 1) + 4

Canonical: ∀ x. ∀ y. x = 5 · y + 3 → x · x = 5 · (y · x + 3 · y + 1) + 4
