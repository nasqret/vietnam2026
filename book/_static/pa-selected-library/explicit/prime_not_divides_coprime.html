prime_not_divides_coprime

A prime not dividing a natural is coprime to that natural.

candidate display only This reading surface grants no kernel, review, freeze, training, retrieval, or evaluation authority.

Exact selected statement

forall p a. (~(p = 1) /\ forall c e. p = c * e -> c = 1 \/ e = 1) -> ~(exists k. a = p * k) -> forall d. (exists x. p = d * x) -> (exists y. a = d * y) -> d = 1

Canonical: ∀ x. ∀ y. ¬x = 1 ∧ (∀ z. ∀ n. x = z · n → z = 1 ∨ n = 1) → ¬(∃ z. y = x · z) → ∀ z. (∃ n. x = z · n) → (∃ n. y = z · n) → z = 1
