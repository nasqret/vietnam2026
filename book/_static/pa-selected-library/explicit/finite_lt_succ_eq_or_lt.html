finite_lt_succ_eq_or_lt

A value below a successor is the predecessor or lies below it.

candidate display only This reading surface grants no kernel, review, freeze, training, retrieval, or evaluation authority.

Exact selected statement

forall n x. (exists h. h + S x = S n) -> x = n \/ exists h. h + S x = n

Canonical: ∀ x. ∀ y. S y ≤ S x → y = x ∨ S y ≤ x
