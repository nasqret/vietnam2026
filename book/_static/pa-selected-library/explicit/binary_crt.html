binary_crt

Constructive binary CRT for positive coprime natural moduli using balanced congruence.

candidate display only This reading surface grants no kernel, review, freeze, training, retrieval, or evaluation authority.

Exact selected statement

forall m n a b. ~(m = 0) -> ~(n = 0) -> (forall d. (exists u. m = d * u) -> (exists v. n = d * v) -> d = 1) -> exists x. (exists u v. x + m * u = a + m * v) /\ (exists r s. x + n * r = b + n * s)

Canonical: ∀ x. ∀ y. ∀ z. ∀ n. ¬x = 0 → ¬y = 0 → (∀ m. (∃ k. x = m · k) → (∃ k. y = m · k) → m = 1) → ∃ m. (∃ k. ∃ i. m + x · k = z + x · i) ∧ (∃ k. ∃ i. m + y · k = n + y · i)
