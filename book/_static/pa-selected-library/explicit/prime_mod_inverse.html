prime_mod_inverse

A nonzero residue modulo a prime has a natural modular inverse.

candidate display only This reading surface grants no kernel, review, freeze, training, retrieval, or evaluation authority.

Exact selected statement

forall p a. (~(p = 1) /\ forall c e. p = c * e -> c = 1 \/ e = 1) -> ~(exists k. a = p * k) -> exists z u v. a * z + p * u = 1 + p * v

Canonical: ∀ x. ∀ y. ¬x = 1 ∧ (∀ z. ∀ n. x = z · n → z = 1 ∨ n = 1) → ¬(∃ z. y = x · z) → ∃ z. ∃ n. ∃ m. y · z + x · n = 1 + x · m
