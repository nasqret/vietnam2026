distinct_primes_coprime

Distinct primes are coprime in the expanded common-divisor relation.

candidate display only This reading surface grants no kernel, review, freeze, training, retrieval, or evaluation authority.

Exact selected statement

forall p q. (~(p = 1) /\ forall c e. p = c * e -> c = 1 \/ e = 1) -> (~(q = 1) /\ forall c e. q = c * e -> c = 1 \/ e = 1) -> ~(p = q) -> forall d. (exists x. p = d * x) -> (exists y. q = d * y) -> d = 1

Canonical: ∀ x. ∀ y. ¬x = 1 ∧ (∀ z. ∀ n. x = z · n → z = 1 ∨ n = 1) → ¬y = 1 ∧ (∀ z. ∀ n. y = z · n → z = 1 ∨ n = 1) → ¬x = y → ∀ z. (∃ n. x = z · n) → (∃ n. y = z · n) → z = 1
