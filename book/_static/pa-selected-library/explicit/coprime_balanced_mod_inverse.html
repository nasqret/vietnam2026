coprime_balanced_mod_inverse

Balanced Bezout coefficients give a subtraction-free modular inverse.

candidate display only This reading surface grants no kernel, review, freeze, training, retrieval, or evaluation authority.

Exact selected statement

forall a m. (forall d. (exists x. a = d * x) -> (exists y. m = d * y) -> d = 1) -> exists xp xn u v. a * xp + m * u = (1 + a * xn) + m * v

Canonical: ∀ x. ∀ y. (∀ z. (∃ n. x = z · n) → (∃ n. y = z · n) → z = 1) → ∃ z. ∃ n. ∃ m. ∃ k. x · z + y · m = 1 + x · n + y · k
