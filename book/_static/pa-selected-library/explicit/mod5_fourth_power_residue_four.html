mod5_fourth_power_residue_four

A number congruent to four modulo five has fourth power congruent to one.

candidate display only This reading surface grants no kernel, review, freeze, training, retrieval, or evaluation authority.

Exact selected statement

forall q. exists w. (5 * q + 4) * (5 * q + 4) * (5 * q + 4) * (5 * q + 4) = 5 * w + 1

Canonical: ∀ x. ∃ y. (5 · x + 4) · (5 · x + 4) · (5 · x + 4) · (5 · x + 4) = 5 · y + 1
