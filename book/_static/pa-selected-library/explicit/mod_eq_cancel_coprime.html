mod_eq_cancel_coprime

A coprime factor cancels from balanced congruence at nonzero modulus.

candidate display only This reading surface grants no kernel, review, freeze, training, retrieval, or evaluation authority.

Exact selected statement

forall m a x y. ~(m = 0) -> (forall d. (exists x. a = d * x) -> (exists y. m = d * y) -> d = 1) -> (exists u v. (a * x) + m * u = (a * y) + m * v) -> exists r s. x + m * r = y + m * s

Canonical: ∀ x. ∀ y. ∀ z. ∀ n. ¬x = 0 → (∀ m. (∃ k. y = m · k) → (∃ k. x = m · k) → m = 1) → (∃ m. ∃ k. y · z + x · m = y · n + x · k) → ∃ m. ∃ k. z + x · m = n + x · k
