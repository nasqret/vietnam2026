beta_at_exists

Every Gödel-beta position has a bounded decoded residue.

candidate display only This reading surface grants no kernel, review, freeze, training, retrieval, or evaluation authority.

Exact selected statement

forall b c i. exists x. ((exists h. h + S x = S ((S i) * c)) /\ exists q. b = q * S ((S i) * c) + x)

Canonical: ∀ x. ∀ y. ∀ z. ∃ n. S n ≤ S (S z · y) ∧ (∃ m. x = m · S (S z · y) + n)
