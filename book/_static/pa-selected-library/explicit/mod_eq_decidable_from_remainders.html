mod_eq_decidable_from_remainders

Canonical bounded remainders constructively decide congruence.

candidate display only This reading surface grants no kernel, review, freeze, training, retrieval, or evaluation authority.

Exact selected statement

forall p a b qa ra qb rb. a = qa * p + ra -> (exists ha. ha + S ra = p) -> b = qb * p + rb -> (exists hb. hb + S rb = p) -> (exists u v. a + p * u = b + p * v) \/ ~(exists u v. a + p * u = b + p * v)

Canonical: ∀ x. ∀ y. ∀ z. ∀ n. ∀ m. ∀ k. ∀ i. y = n · x + m → S m ≤ x → z = k · x + i → S i ≤ x → (∃ j. ∃ u. y + x · j = z + x · u) ∨ ¬(∃ j. ∃ u. y + x · j = z + x · u)
