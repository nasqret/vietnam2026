multiple_has_zero_remainder

Every multiple of a nonzero divisor has a bounded zero-remainder decomposition.

candidate display only This reading surface grants no kernel, review, freeze, training, retrieval, or evaluation authority.

Exact selected statement

forall m n. ~(m = 0) -> (exists q. n = m * q) -> exists q r. (n = m * q + r /\ r = 0) /\ S r <= m

Canonical: ∀ x. ∀ y. ¬x = 0 → (∃ z. y = x · z) → ∃ z. ∃ n. y = x · z + n ∧ n = 0 ∧ S n ≤ x
