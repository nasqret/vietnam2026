multiple_antisymm

Mutual divisibility is antisymmetric over natural numbers.

candidate display only This reading surface grants no kernel, review, freeze, training, retrieval, or evaluation authority.

Exact selected statement

forall a b. (exists x. b = a * x) -> (exists y. a = b * y) -> a = b

Canonical: ∀ x. ∀ y. (∃ z. y = x · z) → (∃ z. x = y · z) → x = y
