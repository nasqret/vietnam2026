mod5_fourth_power_residue_one

A number congruent to one modulo five has fourth power congruent to one.

candidate display only This reading surface grants no kernel, review, freeze, training, retrieval, or evaluation authority.

forall q. exists w. (5 * q + 1) * (5 * q + 1) * (5 * q + 1) * (5 * q + 1) = 5 * w + 1

Canonical: ∀ x. ∃ y. (5 · x + 1) · (5 · x + 1) · (5 · x + 1) · (5 · x + 1) = 5 · y + 1
