prime_unbounded

Euclid's common-multiple argument constructs a prime above every natural.

candidate display only This reading surface grants no kernel, review, freeze, training, retrieval, or evaluation authority.

Exact selected statement

forall n. exists p. (exists k. k + S n = p) /\ (~(p = 1) /\ forall a b. p = a * b -> a = 1 \/ b = 1)

Canonical: ∀ x. ∃ y. S x ≤ y ∧ (¬y = 1 ∧ (∀ z. ∀ n. y = z · n → z = 1 ∨ n = 1))
