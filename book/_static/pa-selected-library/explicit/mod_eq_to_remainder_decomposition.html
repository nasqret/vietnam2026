mod_eq_to_remainder_decomposition

A bounded balanced residue has a directed quotient/remainder witness.

candidate display only This reading surface grants no kernel, review, freeze, training, retrieval, or evaluation authority.

Exact selected statement

forall m b x. ~(m = 0) -> (exists h. h + S x = m) -> (exists u v. b + m * u = x + m * v) -> exists q. b = q * m + x

Canonical: ∀ x. ∀ y. ∀ z. ¬x = 0 → S z ≤ x → (∃ n. ∃ m. y + x · n = z + x · m) → ∃ n. y = n · x + z
