coprime_mod_inverse

A nonzero modulus turns balanced Bezout data into a natural modular inverse.

candidate display only This reading surface grants no kernel, review, freeze, training, retrieval, or evaluation authority.

Exact selected statement

forall a m. ~(m = 0) -> (forall d. (exists x. a = d * x) -> (exists y. m = d * y) -> d = 1) -> exists z u v. a * z + m * u = 1 + m * v

Canonical: ∀ x. ∀ y. ¬y = 0 → (∀ z. (∃ n. x = z · n) → (∃ n. y = z · n) → z = 1) → ∃ z. ∃ n. ∃ m. x · z + y · n = 1 + y · m
