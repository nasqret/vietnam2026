beta_modulus_coprime_base

Every beta-shaped successor modulus is coprime to its base c.

candidate display only This reading surface grants no kernel, review, freeze, training, retrieval, or evaluation authority.

Exact selected statement

forall c k d. (exists u. S (k * c) = d * u) -> (exists v. c = d * v) -> d = 1

Canonical: ∀ x. ∀ y. ∀ z. (∃ n. S (y · x) = z · n) → (∃ n. x = z · n) → z = 1
