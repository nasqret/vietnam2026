division_remainder_unique

Bounded quotient-remainder decompositions have unique quotients and remainders.

candidate display only This reading surface grants no kernel, review, freeze, training, retrieval, or evaluation authority.

Exact selected statement

forall m n q r q2 r2. n = m * q + r -> (exists k. k + S r = m) -> n = m * q2 + r2 -> (exists k. k + S r2 = m) -> q = q2 /\ r = r2

Canonical: ∀ x. ∀ y. ∀ z. ∀ n. ∀ m. ∀ k. y = x · z + n → S n ≤ x → y = x · m + k → S k ≤ x → z = m ∧ n = k
