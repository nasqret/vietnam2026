divisor_le_nonzero

A divisor of a nonzero natural is bounded by that natural.

candidate display only This reading surface grants no kernel, review, freeze, training, retrieval, or evaluation authority.

Exact selected statement

forall d n. ~(n = 0) -> (exists q. n = d * q) -> exists k. k + d = n

Canonical: ∀ x. ∀ y. ¬y = 0 → (∃ z. y = x · z) → x ≤ y
