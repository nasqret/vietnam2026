multiple_decidable_nonzero

Divisibility by a nonzero natural is constructively decidable.

candidate display only This reading surface grants no kernel, review, freeze, training, retrieval, or evaluation authority.

Exact selected statement

forall d n. ~(d = 0) -> (exists q. n = d * q) \/ ~(exists q. n = d * q)

Canonical: ∀ x. ∀ y. ¬x = 0 → (∃ z. y = x · z) ∨ ¬(∃ z. y = x · z)
