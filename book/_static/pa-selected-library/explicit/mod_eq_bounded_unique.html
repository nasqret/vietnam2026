mod_eq_bounded_unique

Two balanced-congruent values below the same modulus are equal.

candidate display only This reading surface grants no kernel, review, freeze, training, retrieval, or evaluation authority.

Exact selected statement

forall m a b. (exists ha. ha + S a = m) -> (exists hb. hb + S b = m) -> (exists u v. a + m * u = b + m * v) -> a = b

Canonical: ∀ x. ∀ y. ∀ z. S y ≤ x → S z ≤ x → (∃ n. ∃ m. y + x · n = z + x · m) → y = z
