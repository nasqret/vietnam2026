prime_divisor_eq_one_or_self

Every divisor of a prime is one or the prime itself.

candidate display only This reading surface grants no kernel, review, freeze, training, retrieval, or evaluation authority.

Exact selected statement

forall p g. (~(p = 1) /\ forall c d. p = c * d -> c = 1 \/ d = 1) -> (exists x. p = g * x) -> g = 1 \/ p = g

Canonical: ∀ x. ∀ y. ¬x = 1 ∧ (∀ z. ∀ n. x = z · n → z = 1 ∨ n = 1) → (∃ z. x = y · z) → y = 1 ∨ x = y
