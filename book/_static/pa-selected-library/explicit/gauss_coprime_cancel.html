gauss_coprime_cancel

Cancel a coprime factor from a divisibility witness (Gauss cancellation).

candidate display only This reading surface grants no kernel, review, freeze, training, retrieval, or evaluation authority.

Exact selected statement

forall a b z. (forall d. (exists x. a = d * x) -> (exists y. b = d * y) -> d = 1) -> (exists q. b * z = a * q) -> exists w. z = a * w

Canonical: ∀ x. ∀ y. ∀ z. (∀ n. (∃ m. x = n · m) → (∃ m. y = n · m) → n = 1) → (∃ n. y · z = x · n) → ∃ n. z = x · n
