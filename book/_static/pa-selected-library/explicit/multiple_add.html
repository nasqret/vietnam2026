multiple_add

Multiples of a fixed number are closed under addition.

candidate display only This reading surface grants no kernel, review, freeze, training, retrieval, or evaluation authority.

Exact selected statement

forall a n m. (exists q. n = a * q) -> (exists r. m = a * r) -> exists s. n + m = a * s

Canonical: ∀ x. ∀ y. ∀ z. (∃ n. y = x · n) → (∃ n. z = x · n) → ∃ n. y + z = x · n
