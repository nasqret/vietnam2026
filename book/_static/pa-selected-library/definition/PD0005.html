PD0005 Coprime

Conservative reading notation

candidate display only This reading surface grants no kernel, review, freeze, training, retrieval, or evaluation authority.

Meaning

Every common divisor of a and b is one.

Parameters: a, b

forall d. (exists x. a = d * x) -> (exists y. b = d * y) -> d = 1
