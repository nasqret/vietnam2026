PD0036 InverseIndex

Conservative reading notation

candidate display only This reading surface grants no kernel, review, freeze, training, retrieval, or evaluation authority.

Meaning

i and j are bounded zero-based modular inverse indices.

Parameters: m, l, i, j

((exists dp_left_gap. dp_left_gap + S i = l) /\ ((exists dp_right_gap. dp_right_gap + S j = l) /\ (exists dp_u dp_v. (S i) * S j + m * dp_u = 1 + m * dp_v)))
