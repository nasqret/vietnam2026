PD0006 IsGCD

Conservative reading notation

candidate display only This reading surface grants no kernel, review, freeze, training, retrieval, or evaluation authority.

Meaning

g is a common divisor divisible by every common divisor.

Parameters: g, a, b

((exists x. a = g * x) /\ (exists y. b = g * y)) /\ forall d. (exists u. a = d * u) -> (exists v. b = d * v) -> exists w. g = d * w
