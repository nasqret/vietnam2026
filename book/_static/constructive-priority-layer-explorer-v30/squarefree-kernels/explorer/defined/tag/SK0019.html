SK0019

prime_valuation_divisible_power_root_bounded

Construct a k-th root from divisibility of every prime valuation by strict full-prime-power descent; every quotient and recursive root is actually derived.

Alpha v30 checked-use · first admitted v29 · independently kernel and Lean verified; not Stable

For n>1 the exponent gcd and a real beta table classify and witness all positive root degrees. The unit n=1 has a separate uniform certificate for every positive degree. Zero is excluded. NaturalSquarefreeDecomposition is deliberately distinct from the unrelated polynomial definition.

Exact theorem in conservative defined notation

∀ B. ∀ n. ∀ k. ¬n = 0 → ¬k = 0 → PrimeValuationsDivisible(n,k) → Lt(n,B) → ∃ x. Pow(x,k,n)

Every linked abbreviation expands hygienically to the identical original native formula.
