prime_exponent_entries_restore_prime_power

Restoring a removed full prime power preserves every old positive valuation, because its base prime is absent from the cofactor.

Alpha v30 checked-use · first admitted v29 · independently kernel and Lean verified; not Stable

This is a shared constructive tool, not an additional major blueprint goal. The list covers every prime divisor, has no repeated primes, and contains actual prime-power values. One uses the empty support; zero is excluded.
