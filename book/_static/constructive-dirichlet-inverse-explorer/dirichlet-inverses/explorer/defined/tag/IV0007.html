dirichlet_inverse_zero

Every pair of actual zero-window tables has a genuine delta witness and both empty positive-domain inverse identities, with no condition at one.

Local checkpoint: original HA and independently compiled Lean verified; not Alpha-enrolled, no Alpha checked-use authority; not Stable

For an actual table, an inverse exists exactly when N=0 or F(1) is signed +1 or -1. At N>0 this is the usual unit-at-one criterion. Its zeroth value is arbitrary, so uniqueness concerns only positive represented values, not table codes or zero.
