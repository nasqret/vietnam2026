DU0002

dirichlet_kronecker_delta_table_one_value

The actual entry at index one is signed one whenever that index lies in the finite table domain.

Local checkpoint: original HA and independently compiled Lean verified; not Alpha-enrolled, no Alpha checked-use authority; not Stable

Signed one is canonical code 2. Positive-only table graphs preserve arbitrary zeroth values, including N=0. The unit and divisor-sum identities are proved separately, never embedded as assumptions in the definitions. The arbitrary-unit inverse criterion of G009 remains open.
