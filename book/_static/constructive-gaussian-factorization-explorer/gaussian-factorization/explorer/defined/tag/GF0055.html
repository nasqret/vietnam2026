gaussian_associate_symmetric

Invert the actual unit witness to reverse Gaussian association, including the zero boundary.

Alpha v30 checked-use · first admitted v30 · independently kernel and Lean verified; not Stable

Inputs are genuine canonical signed-pair codes, not arbitrary naturals. Products start at the actual Gaussian identity, whose code is six.
