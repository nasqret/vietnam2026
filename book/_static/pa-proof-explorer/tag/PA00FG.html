Build the common Gauss–Eisenstein data package

Curated informal proof

For two distinct odd primes, construct both oriented Gauss half-system counts at once. The preceding finite-fold, bounded-remainder, permutation, and Euler/Gauss lemmas show that each count classifies the corresponding cross-residue proposition.

Eisenstein's lattice count supplies the shared parity relation: after transporting both counts modulo two, their sum is the product of the two half-prime parameters. The theorem retains all witnesses, so the two final reciprocity cases can reuse one provenance-preserving data package.
