cornacchia_stopped_trace

A below-threshold positive state is a complete zero-transition Cornacchia run with stored terminal quotient zero.

Alpha v27 checked-use · first admitted v27 · independently kernel and Lean verified; not Stable

The output equation is proved from the real first-stop execution; it is not a trace-definition assumption. This is the prime sum-of-two-squares Cornacchia theorem, not a general x²+d y² solver.
