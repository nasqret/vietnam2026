MC0002

prime_toggle_fresh_divisor_product

A prime divisor of n not dividing d can be adjoined to an actual divisor d: Euclid cancellation constructs the required quotient.

Local checkpoint: original HA and independently compiled Lean verified; not Alpha-enrolled, no Alpha checked-use authority; not Stable

The input n is positive. Canonical signed code 2 denotes +1, so the sum is +1 at n=1 and zero for n>1. The positive-values theorem permits arbitrary F(0); the genuine divisor mask excludes it. Prime-square multiples contribute zero. This proves divisor cancellation, not the full Möbius inversion or convolution equivalence; full G007 remains open.

Exact theorem in conservative defined notation

∀ p. ∀ n. ∀ d. Prime(p) → Dvd(p,n) → Dvd(d,n) → ¬Dvd(p,d) → Dvd(p · d,n)
