divisor_complement_prefix_positive_quotient

The actual beta code at a positive divisor is precisely its witnessed quotient, not merely an unspecified bounded permutation image.

Local checkpoint: original HA and independently compiled Lean verified; not Alpha-enrolled, no Alpha checked-use authority; not Stable

The complementary quotient is witnessed by n=d*q at positive divisors. The actual permutation covers indices 0 through n, with zero and nondivisors fixed. This is an involution foundation, not Möbius inversion; full G007 remains open.
