signed_rectangular_slice_sum_empty_value

Every actual empty affine sum is the canonical signed zero, irrespective of offset or stride.

Local checkpoint: original HA and independently compiled Lean verified; not Alpha-enrolled, no Alpha checked-use authority; not Stable

Every slice, row table, column table and signed sum is an actual beta-coded witness. The grid entry is F((o+s*i)+t*j), for i<m and j<n.
