A common divisor of two ordered beta moduli divides the index gap times c.

Exact expanded PA statement

forall c i j gap d. j = i + gap -> (exists u. S ((S i) * c) = d * u) -> (exists v. S ((S j) * c) = d * v) -> exists w. gap * c = d * w
